# Code of Conduct

## The short version

Be rigorous and kind. Attack code, arguments, and evidence — never people.

## In this repository specifically

- Claims here carry evidence by design. If you disagree with a claim, the
  strongest contribution is a command that fails — open an issue with it.
- Criticism of the tool's limits (see `spec/conformance.md`) is welcome and
  has historically produced the best fixes.
- No harassment, personal attacks, doxxing, or spam. Maintainers may remove
  comments and block accounts for these.

## Scope

Applies to this repository's issues, pull requests, discussions, and any
project space representing it.

## Reporting

Use GitHub's private contact/reporting on this repository for conduct
reports. Reports are handled by the maintainer; anything involving the
maintainer's own conduct goes to GitHub staff via repository report tooling.
